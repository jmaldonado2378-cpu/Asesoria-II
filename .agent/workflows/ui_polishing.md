---
description: Pulido de Interfaz (ui_polishing)
---

Para cada tarea de UI, asegura los siguientes estándares de calidad:

1. **Mobile First**: La interfaz debe ser completamente funcional y estética en dispositivos móviles.
2. **Feedback Visual**: Todos los botones de acción deben incluir estados de carga (`loading`) y deshabilitarse durante procesos asíncronos.
3. **Tematización**: Respetar estrictamente la paleta de colores y el soporte para modo oscuro/claro definido en el sistema.
4. **Premium Feel**: Añadir micro-animaciones y transiciones suaves para mejorar la experiencia del usuario.
